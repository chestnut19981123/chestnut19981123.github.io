## 二分

二分解决的是"二段性"问题——数组在某处分界，一边满足条件一边不满足（左0右1或左1右0）。`check` 就是分界处的判定条件：`check(nums[mid])` 为真表示进入"目标区"。

模板用红绿灯法统一实现：**把满足 `check` 的区域看成绿灯区，不满足的是红灯区，二分就是找红绿灯交界处第一个绿灯的位置**。只需记住一条规则：

* `left` 初始为 `-1`、`right` 初始为 `nums.length`，分别看作"最左的红灯哨兵"和"最右的绿灯哨兵"
* `check` 为真（绿灯）：`right = mid`；为假（红灯）：`left = mid`
* 循环到 `right - left == 1` 结束，返回 `right`——全部不满足时返回 `n`，不会越界

### 整数二分查找

```java
class BinarySearchUnified {
    // 红绿灯法统一模板：返回第一个 check 为真的下标
    public int binarySearch(int[] nums, java.util.function.IntPredicate check) {
        int left = -1, right = nums.length; // 开区间 (left, right)
        while (right - left > 1) {
            int mid = left + (right - left >> 1);
            if (check.test(mid)) {
                right = mid;    // 绿灯区，左移右边界
            } else {
                left = mid;     // 红灯区，推进左边界
            }
        }
        return right;
    }

    // 用法1：找第一个 >= target（左边界）；返回 n 表示不存在
    public int firstGreaterEqual(int[] nums, int target) {
        return binarySearch(nums, mid -> nums[mid] >= target);
    }

    // 用法2：找最后一个 <= target（右边界）——先找第一个 > target 再减一；返回 -1 表示不存在
    public int lastLessEqual(int[] nums, int target) {
        return binarySearch(nums, mid -> nums[mid] > target) - 1;
    }
}
```

两个用法示例覆盖了左边界和右边界两种场景，`check` 怎么写全看题目条件。记住这一套，`+1` 的烦恼就没有了。

### 浮点二分查找

```java
class FloatBinarySearch {
    // 浮点二分：在 (left, right) 内逼近 check 为真的边界，eps 控制精度
    public double floatBinarySearch(double left, double right, java.util.function.DoublePredicate check) {
        final double eps = 1e-6; // eps表示精度
        while (right - left > eps) {
            double mid = (left + right) / 2;
            if (check.test(mid)) { // check：左红右绿，常为f[mid] >= target
                right = mid;
            } else {
                left = mid;
            }
        }
        return left;
    }
}
```

## 搜索

DFS 一条路走到黑，BFS 一圈一圈往外扩散。各自来一份：

### 深度优先搜索

```java
class DFS {
    // 深度优先搜索递归实现
    public void dfs(int node, boolean[] visited, List<List<Integer>> graph) {
        // 访问当前节点
        visited[node] = true;
        System.out.print(node + " ");

        // 访问邻接节点
        for (int neighbor : graph.get(node)) {
            if (!visited[neighbor]) {
                dfs(neighbor, visited, graph);
            }
        }
    }

    // 演示：构建图并调用 dfs 遍历
    public void caller() {
        int numNodes = 5;
        // 构建图的邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numNodes; i++) {
            graph.add(new ArrayList<>());
        }
        // 添加边
        graph.get(0).add(1);
        graph.get(0).add(2);
        graph.get(1).add(3);
        graph.get(1).add(4);

        System.out.print("DFS starting from node 0: ");
        boolean[] visited = new boolean[numNodes];
        dfs(0, visited, graph);
    }
}
```

### 广度优先搜索

```java
class BFS {
    // 广度优先搜索队列实现
    public void bfs(int node, int numNodes, List<List<Integer>> graph) {
        boolean[] visited = new boolean[numNodes];
        Deque<Integer> queue = new LinkedList<>();

        // 起始节点入队
        visited[node] = true;
        queue.offer(node);

        while (!queue.isEmpty()) {
            // 访问队头节点
            int currentNode = queue.poll();
            System.out.print(currentNode + " ");

            // 邻接节点入队
            for (int neighbor : graph.get(currentNode)) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.offer(neighbor);
                }
            }
        }
    }

    // 演示：构建图并调用 bfs 遍历
    public void caller() {
        int numNodes = 5;
        // 构建图的邻接表
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numNodes; i++) {
            graph.add(new ArrayList<>());
        }
        // 添加边
        graph.get(0).add(1);
        graph.get(0).add(2);
        graph.get(1).add(3);
        graph.get(1).add(4);

        System.out.print("BFS starting from node 0: ");
        bfs(0, numNodes, graph);
    }
}
```

### BFS求最短路径

无权图的最短路就是 BFS 的活——`dist` 数组记录距离，第一次访问到某个节点时的层数就是最短距离：

```java
class BFSShortestPath {
    public int[] bfsShortestPath(int start, int numNodes, List<List<Integer>> graph) { // 返回各节点到 start 的最短距离
        int[] dist = new int[numNodes];
        Arrays.fill(dist, -1); // -1 表示不可达
        Deque<Integer> queue = new LinkedList<>();
        dist[start] = 0;
        queue.offer(start);

        while (!queue.isEmpty()) {
            int cur = queue.poll();
            for (int neighbor : graph.get(cur)) {
                if (dist[neighbor] == -1) { // 首次访问即最短
                    dist[neighbor] = dist[cur] + 1;
                    queue.offer(neighbor);
                }
            }
        }
        return dist;
    }
}
```

## 排序

快排靠枢轴划分，能顺带解决第 K 大问题；归并靠合并两个有序段，还能顺手做逆序对计数。面试手写这两个就够用，实际工程直接 `Arrays.sort` 完事。

### 快速排序

1. 若`left >= right`则直接返回（`[left, right]`闭区间）
2. 使用`pivotPos`划分列表
   1. 选最左元素赋值给`pivot`，`i`指向`left`、`j`指向`right`
   2. 移动指针`j`(后至前)找到第一个小元素时交换，小元素严格小于`pivot`，j处元素交换到i所指位置
   3. 移动指针`i`(前至后)找到第一个大元素时交换，大元素严格大于`pivot`，i处元素交换到j所指位置
   4. 重复23直至`i == j`，交换`pivot`与`nums[i]`
3. 对左半部分递归地进行快速排序
4. 对右半部分递归地进行快速排序

```java
class QuickSort {
    public void quickSort(int[] nums, int left, int right) { // 快速排序[left, right]
        // 递归出口
        if (left >= right) return;

        int pivotPos = partition(nums, left, right);
        quickSort(nums, left, pivotPos - 1); // 排序左半段
        quickSort(nums, pivotPos + 1, right); // 排序右半段
    }

    private int partition(int[] nums, int left, int right) { // 划分
        int pivot = nums[left]; // 第一个元素作为枢轴
        while (left < right) {
            while (left < right && nums[right] >= pivot) right--; // 找到第一个较小数
            nums[left] = nums[right];
            while (left < right && nums[left] <= pivot) left++; // 找到第一个较大数
            nums[right] = nums[left];
        } // left == right且 left左数小于pivot right右数大于pivot
        nums[left] = pivot; // 放置枢轴
        return left; // 返回枢轴位置
    }
}
```

### 归并排序

1. 若`left >= right`则直接返回（`[left, right]`闭区间）
2. 划分空间、计算`mid`（`int mid = left + (right - left >> 1)`）;
3. 对左半部分递归地进行归并排序
4. 对右半部分递归地进行归并排序
5. 将左右两个有序的子序列`merge`为一个
   1. 复制所有元素至数组B
   2. `i`, `j`, `k`指向归并段1(`left`),归并段2(`mid+1`), 表头`left`
   3. 比较`B[i]`与`B[j]`，复制较小值至`A[k]`
   4. `i`或`j`(上一步选择的较小值)以及`k`自增
   5. 重复34直至`i > mid`或`j > high`
   6. 复制第一个表或第二个表剩余元素

```java
class MergeSort {
    private int[] mergeArray;

    public void mergeSort(int[] nums, int left, int right) { // 归并排序[left, right]
        // 递归出口
        if (left >= right) return;

        // 划分空间 可放置到主函数
        if (this.mergeArray == null) this.mergeArray = new int[right - left + 1];

        int mid = left + (right - left >> 1);
        mergeSort(nums, left, mid); // 排序左半段
        mergeSort(nums, mid + 1, right); // 排序右半段

        merge(nums, left, mid, right);
    }

    private void merge(int[] nums, int left, int mid, int right) { // 归并
        // 复制数组
        for (int k = left; k <= right; k++) mergeArray[k] = nums[k];

        int i = left, j = mid + 1, k = left;
        while (i <= mid && j <= right) {
            if (mergeArray[i] <= mergeArray[j]) {
                nums[k++] = mergeArray[i++];
            } else {
                nums[k++] = mergeArray[j++];
            }
        }
        while (i <= mid) nums[k++] = mergeArray[i++]; // 统计剩余左半段
        while (j <= right) nums[k++] = mergeArray[j++]; // 统计剩余右半段
    }
}
```

## 图论

图论题从并查集开始——连通性判断、最小生成树都离不开它。下面依次是并查集、Dijkstra 最短路、Kruskal 最小生成树：

### 并查集

并查集用于解决连通性问题。

```java
/**
 * 并查集
 */
class UnionFind {
    // 父亲数组
    int[] parent;
    
    /**
     * 初始化
     */
    public UnionFind(int n) {
        parent = new int[n];
        // 初始状态下，每个节点的父亲都是自己
        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }
    }

    /**
     * 将指定节点 v 并入指定节点 u
     */
    public void union(int u, int v) {
        parent[find(v)] = find(u);
    }

    /**
     * 查找指定节点 x 父亲
     */
    public int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路径压缩
        }
        return parent[x];
    }
}
```

### Dijkstra

带权最短路，标准写法是邻接表 + 优先队列。核心思想：每次从"已确定最短路的集合"出发，松弛相邻节点：

```java
class Dijkstra {
    // graph.get(u) 存放 int[]{v, w}，表示 u 到 v 的边权为 w
    public int[] dijkstra(int start, int numNodes, List<List<int[]>> graph) {
        int[] dist = new int[numNodes];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[start] = 0;

        // 优先队列按距离升序，int[]{距离, 节点}
        PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
        pq.offer(new int[]{0, start});

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int d = cur[0], u = cur[1];
            if (d > dist[u]) continue; // 过期条目，跳过

            for (int[] edge : graph.get(u)) {
                int v = edge[0], w = edge[1];
                if (dist[u] + w < dist[v]) { // 松弛
                    dist[v] = dist[u] + w;
                    pq.offer(new int[]{dist[v], v});
                }
            }
        }
        return dist;
    }
}
```

### Kruskal

最小生成树，思路就一句话：边按权重从小到大排，只要不形成环就选——判环正好用上面的并查集：

```java
class Kruskal {
    // edges: int[]{u, v, w}，无需排序，函数内部按权重升序处理
    public int kruskal(int n, int[][] edges) {
        Arrays.sort(edges, (a, b) -> a[2] - b[2]);
        UnionFind uf = new UnionFind(n);
        int cost = 0, cnt = 0;
        for (int[] e : edges) {
            if (uf.find(e[0]) != uf.find(e[1])) { // 不成环才选
                uf.union(e[0], e[1]);
                cost += e[2];
                cnt++;
                if (cnt == n - 1) break; // n 个节点 n-1 条边即完工
            }
        }
        return cnt == n - 1 ? cost : -1; // -1 表示图不连通
    }
}
```

## 其他

### 前缀和

前缀和用于计算子数组和，常需用到`TreeMap`/`HashMap`快速查找满足某条件和的下标。

* `HashMap`对应相等条件，`TreeMap`对应不等条件。
* `TreeMap`的`ceilingKey`/`higherKey`对应`>=`/`>`指定值的最小键，`floorKey`/`lowerKey`对应`<=`/`<`指定值的最大键。

```java
class PrefixSum {
    // 计算前缀和，prefix[i] = sum[0..(i-1)]
    public int[] prefixSum(int[] nums) {
        // TreeMap<Integer, Integer> map = new TreeMap<>();
        // map.put(0, 0);
        int[] prefix = new int[nums.length + 1]; // prefix[i] = sum[0..(i-1)]
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
            // map.put(prefix[i + 1], i + 1);
        }
        return prefix;
    }
}
```

### 差分数组

差分是前缀和的"反向操作"：前缀和求区间和，差分做区间加减。对区间 $[l, r]$ 加 $val$，只需改两个位置，最后前缀和还原：

```java
class DifferenceArray {
    // ops: int[]{l, r, val}，对 nums 的 [l, r] 区间加 val
    public int[] difference(int[] nums, int[][] ops) {
        int n = nums.length;
        int[] diff = new int[n + 1];
        for (int[] op : ops) {
            diff[op[0]] += op[2];
            diff[op[1] + 1] -= op[2];
        }
        int[] res = nums.clone();
        int cur = 0;
        for (int i = 0; i < n; i++) {
            cur += diff[i];
            res[i] += cur;
        }
        return res;
    }
}
```
