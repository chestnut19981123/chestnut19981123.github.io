# 设计文档：《常见代码模板》封面重设计

- 日期：2026-08-04
- 目标：为《常见代码模板》（`source/_posts/算法/常见代码模板.md`）重做一张艺术风格封面，替换现有的浅色代码编辑器风格 `cover.jpg`

## 设计决策（经用户逐项确认）

| 维度 | 决策 |
|---|---|
| 风格方向 | 浅色艺术风，延续博客封面家族（亮度 ~240 的淡蓝紫浅底） |
| 主体元素 | 算法概念可视化，不画代码 |
| 标题文字 | 纯图形无文字 |
| 画面比例 | 方形 1:1（与家族一致，卡片 42% 宽 / 移动端 100%×230px 裁切安全） |
| 构图 | 三联画（方案 B）——横向三等分，呼应文章开头「几板斧」意象 |

## 构图与元素

方形画布横向三等分（三竖条），分格间留白间隔、不画分隔线：

1. **左格·排序**：一排圆顶竖柱，柱高低→高→低拱形排列，柱色橙→蓝渐变，柱底浅色基线
2. **中格·二分**：垂直红→绿渐变（上红下绿），交界处一道白色细刻线 + 绿色光晕小圆点（「第一个绿灯」，文章招牌思想）
3. **右格·图论**：蓝色节点 + 浅灰连线网络，其中一条路径橙色高亮（暗合 DFS/BFS「一条路走到黑」）

光影：每格中心一朵主色径向光晕（alpha ≈ 0.15–0.25），营造「光从格子里透出」的效果。
