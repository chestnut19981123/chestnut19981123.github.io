## 目标

将公式型笔记改写为「讲解+公式结合」的博客文章，丰富物理直觉与记忆方法，语言幽默风趣但不油腻，延续《求导积分速查表》的轻松备考风格。

## 结构

1. **开场**：场积分的世界观——普通积分在区间上求和，场积分把舞台换成曲线/曲面/区域；数量场像温度，向量场像水流
2. **数量场积分**：第一类线积分（不均匀铁丝的质量）、第一类面积分（不均匀果皮/布料的质量）
3. **向量场积分**：第二类线积分（力做功）、第二类面积分（通量）——方向性与 $\pm$ 号
4. **三大公式**：Green（2D 边界环量 = 区域旋度）、Gauss（表面通量 = 散度体积分）、Stokes（边界环量 = 旋度通量）；Green 是 Stokes 的 2D 表亲；维度升降记忆
5. **易错点清单 + 收尾**
