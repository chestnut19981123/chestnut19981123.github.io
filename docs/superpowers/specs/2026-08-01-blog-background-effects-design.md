# 博客背景特效重构 — 设计文档

日期：2026-08-01
状态：已批准

## 背景与目标

博客（Hexo + Butterfly 主题）当前开启了三层背景特效：动态彩带（canvas_fluttering_ribbon）、鼠标点击烟花（fireworks）、以及关闭中的粒子连线（canvas_nest）。两层"全屏持续漂浮"的特效（彩带与粒子）会互相干扰、视觉杂乱。

目标：引入安静的粒子连线背景，关闭与之生态位冲突的动态彩带，保留瞬发交互的点击烟花，形成"一层持续背景 + 一层瞬发互动"的清晰层次。整体保持克制、简洁的视觉基调。

## 范围

- **只改动** `_config.butterfly.yml` 中的背景特效配置段。
- **不新增文件**，**不引入自定义代码**，全部使用 Butterfly 主题内置能力（纯声明式配置，主题升级无兼容风险）。
- **保持不变**：博客名称「一粟」、主题色 #49b1f5、banner 图、封面、副标题、加载动画等其他一切配置。

## 具体改动

`_config.butterfly.yml` 中：

### 1. 开启粒子连线（canvas_nest）

```yaml
canvas_nest:
  enable: true
  color: '70,140,220'   # 深蓝 rgb(70,140,220)，白色背景上清晰可见，与主题蓝 #49b1f5 (73,177,245) 同色系
  opacity: 0.7          # 保持默认
  zIndex: -1            # 保持在内容下方，不遮挡阅读
  count: 99             # 保持默认
  mobile: false         # 移动端不开启（性能考虑），保持默认
```

### 2. 关闭动态彩带

```yaml
canvas_fluttering_ribbon:
  enable: false
```

### 3. 保留点击烟花（不改动）

```yaml
fireworks:
  enable: true
  zIndex: 9999
  mobile: false
```

## 决策记录

| 决策 | 理由 |
|------|------|
| 粒子连线 vs 动态彩带：二选一，留粒子 | 两者同为"全屏持续漂浮"的背景层，叠加会互相干扰；粒子单色低饱和、气质克制，彩带高饱和彩色、视觉最花哨，与本次"简洁克制"的方向相悖 |
| 保留点击烟花 | 烟花为瞬发交互层（点击后 0.5~1 秒消失），不与任何持续背景冲突，且保留互动惊喜感，零持续视觉成本 |
| 粒子用深蓝 `70,140,220` | 白色背景上清晰可见，与主题色 #49b1f5 同色系保持整体协调 |
| 移动端关闭粒子 | 性能考虑，且移动端屏幕小，特效收益低 |
| 纯配置实现（方案 A） | 零代码、零风险、随主题升级兼容，符合"基础视觉"的范围 |

## 验证方式

1. `npm run server` 本地启动，检查首页：
   - 深蓝粒子连线出现于内容下方
   - 动态彩带不再出现
   - 点击任意位置仍有烟花特效
2. 浏览器窗口缩窄至移动端宽度：粒子不出现（按配置）
3. 确认无误后 push 到 `main`，GitHub Actions 自动构建并部署到 GitHub Pages

## 回滚方案

改动仅涉及 `_config.butterfly.yml` 一个文件的两个配置段，如需回滚，恢复 canvas_nest.enable 为 false、canvas_fluttering_ribbon.enable 为 true 即可。
